# Portfolio SBI4U | Biologie

Portfolio électronique de biologie 12e année (SBI4U). Site statique : un seul fichier, `index.html`, sans dépendances.

## Publier avec GitHub Pages
1. Créer un dépôt **public** sur github.com (ex. `portfolio-sbi4u`).
2. **Add file → Upload files**, glisser `index.html` (et ce `README.md`), puis **Commit changes**.
3. **Settings → Pages → Build and deployment → Deploy from a branch**, choisir `main` et `/ (root)`, puis **Save**.
4. Après 1 à 2 minutes, le site est à `https://VOTRE-NOM.github.io/portfolio-sbi4u/`.

## Modifier le contenu
Ouvrir `index.html` sur GitHub, cliquer sur le crayon (Edit), changer le texte, puis **Commit changes**. Le site se met à jour en quelques minutes.

Le bouton « Modifier le contenu » est caché pour les visiteurs. Il apparaît avec `?edit` à la fin de l'adresse, mais les changements faits ainsi restent seulement dans votre navigateur.
